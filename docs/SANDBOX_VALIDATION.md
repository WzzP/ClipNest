# 沙盒验证版

本地实验版本，不是已通过 Mac App Store 审核的发行包。

## 构建与运行

```sh
./scripts/build-sandbox.sh
open '.build/sandbox/ClipNest.app'
```

- 独立标识：`com.clipnest.sandbox`，名称：ClipNest。
- 优先使用 Command + Shift + V；若已被占用，沙盒版改用 Control + Command + Shift + V。菜单栏提示显示实际组合。
- 应用数据使用系统沙盒容器 `~/Library/Containers/com.clipnest.sandbox/Data/Library/Application Support/ClipNest`。不自动导入原版历史。
- 当前为 ad-hoc 本地签名。原版的辅助功能授权不会转移给不同标识的验证版，重建后授权也可能失效。
- 权限仅包含 App Sandbox、用户选择文件只读、应用作用域书签。没有网络权限或沙盒临时例外。书签权限为后续验证准备，现有文件历史还未实现书签持久化。

## 自动检查

```sh
./scripts/test-sandbox.sh
```

脚本构建并运行两个独立进程：第一个写入三条合成记录，第二个恢复并重新复制；使用专用剪贴板，不改系统通用剪贴板。检查文本、PNG 图片、容器内文件，以及未授权容器外测试文件的读取被拒绝。每次只重置沙盒容器内 `SandboxValidation` 合成测试目录。

报告位于 `.build/sandbox-validation/seed.json` 与 `verify.json`。`passed` 仅指这些合成测试，不代表自动粘贴或任意外部文件通过。辅助功能仅执行无提示状态查询，不触发授权、不发送模拟键盘事件。

2026-09-13 实测：沙盒权限已签入，数据路径进入独立容器；三类合成记录跨进程恢复及复制通过；未授权外部测试文件读取被拒绝。常规历史、缩略图、输入法与滚动检查通过。

## 手动验证顺序

1. 启动验证版，在其他应用复制普通测试文本和图片，用 Command + Shift + V（冲突时为 Control + Command + Shift + V）检查记录。这一步验证通用剪贴板和跨应用捕获，不能用专用剪贴板测试替代。
2. 在文本编辑器的空白测试文档中放置光标，唤起验证版，选择记录并点击粘贴。若需要，通过系统设置单独授权 ClipNest，再重复。记录目标应用及是否真正插入内容；“已发送指令”本身不算成功。
3. Finder 复制一个无敏感内容的外部测试文件，检查记录并尝试粘贴到测试文件夹。退出并重新启动验证版，再次尝试。当前没有安全作用域书签实现，外部文件跨启动访问仍是未解决风险。
4. 验证快捷键、中文输入法、双屏与全屏应用，再检查登录启动的开启和关闭。登录启动只在用户主动打开开关时注册。

自动粘贴、外部文件授权及跨重启访问、通用剪贴板监控、登录启动暂未在本次自动检查中验证。后续应根据这些实测决定商店版适配，不应为了让测试通过而关闭沙盒。
