# ClipNest 产品形态与交互草案 v0.1

状态：供讨论的第一轮设计，尚未实现系统剪贴板能力。

## 产品定位

原生 macOS 剪贴板工具：复制后自动留存，需要时快速找回。面向日常写作、开发和资料整理，优先保证快、安静、可控。菜单栏常驻，无需把主窗口一直放在桌面上。第一版数据仅保存在本机。

## 界面形态

- 主入口：全局快捷键唤出当前屏幕底部面板；菜单栏点击提供同一入口。建议快捷键 ⌘⇧V，可修改，注册冲突时提示改键。
- 历史面板：搜索、全部/收藏、历史卡片、当前条目操作及快捷键提示。新记录在前；会话内新复制不打乱用户当前选择。
- 卡片：来源应用、类型、正文摘要、复制时间、收藏标记；选择态使用清晰边框，颜色不作为唯一识别方式。
- 预览：空格展开完整内容；Esc 先关闭预览，再关闭面板。
- 设置：独立小窗口，包含快捷键、登录启动、保存期限/数量、排除应用、暂停记录、删除历史。
- 后续：图片缩略图与大图预览、自定义收藏分组。首版不加入云同步、账号、AI 整理或多窗口资料库。

## 关键交互约定

| 操作 | 结果 |
| --- | --- |
| 唤出 | 记住原前台应用并聚焦搜索，默认选中最新记录 |
| 输入关键词 | 按内容和应用名过滤；空结果显示明确提示 |
| 点击卡片 | 只选中，避免误粘贴 |
| 方向键 | 移动选择，并让选中项保持可见 |
| 空格 | 卡片焦点下切换预览；搜索输入框中正常输入空格 |
| Enter / 双击卡片 | 把内容粘贴到唤出前的目标应用，成功后关闭面板 |
| 复制按钮（原生实现） | 写入剪贴板；仅确认复制，不声称已粘贴 |
| 收藏 | 就地更新；收藏不因普通历史数量上限被自动移除 |
| 暂停记录 | 显示持续暂停状态，旧历史仍可搜索和使用 |
| Esc / 点击外部 | 关闭面板并归还焦点 |

自动粘贴在原生实现中需要按实际技术路径获得辅助功能授权。未授权时提供明确的“复制”操作，提示回原应用按 ⌘V；无法确认目标或发送失败时不得报告粘贴成功。授权请求放在首次使用自动粘贴时。

## 空状态与数据边界

- 首次无历史：展示“复制一段文字，ClipNest 会把它保存在这里”。
- 搜索为空：保留搜索词并提供清除操作。
- 尊重敏感/禁止留存的剪贴板标记；支持应用排除，不能承诺识别所有敏感内容。
- 不记录由自身再次复制产生的重复条目；普通重复内容更新位置与时间。
- 单条删除提供短时撤销；清空历史需确认，并明确是否包含收藏。
- 暂停与持久化失败必须有持续可见状态；只在真实写入成功后显示已保存。

## 视觉与动效

使用系统字体、浅深色适配和低饱和中性色；蓝色用于选中及主操作。原生版本可使用系统材质，但应保证正文对比度，支持降低透明度。正文卡片重在可读性，不按来源应用铺大面积颜色。

选中反馈约 120ms；面板唤出目标 180–220ms，位置变化轻微。动效可中断，不能阻塞快捷键，遵循系统减少动态效果设置。VoiceOver 读出类型、来源、内容摘要和选择状态。

## 本轮原型范围

内嵌草案使用四条样例数据，实现搜索、收藏、暂停状态、选中、全文预览、键盘操作，以及向模拟备忘录粘贴。可通过设计选项对比底部卡片和紧凑列表。没有连接真实剪贴板、全局快捷键、磁盘存储或系统权限。

设计流程：已运行 `npx ui-skills start`，查看 interaction 分类，采用 `wshobson/interaction-design` 的反馈、过渡、可中断性与减少动态效果原则。

下一步讨论：优先确认底部卡片还是紧凑列表，以及首版是否必须支持图片；再进入 SwiftUI/AppKit 的可运行实现。

已落地底部卡片、文本/链接历史、本地保存、搜索、收藏、暂停、数量上限、应用排除、预览、复制与带辅助功能检查的自动粘贴。全局快捷键暂固定为 ⌘⇧V。单条删除暂用确认框替代撤销；图片、自定义分组、登录启动和可配置快捷键后续实现。
