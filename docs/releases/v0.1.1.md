# ClipNest 0.1.1

原生 macOS 剪贴板管理工具，支持 macOS 14 及更新版本。

## 下载

下载 **ClipNest-0.1.1-universal-unsigned.zip**，解压后将 **ClipNest.app** 放入“应用程序”目录。支持 Apple Silicon 和 Intel；本次运行验证在 Apple Silicon 完成。SHA256SUMS.txt 用于校验下载文件。

## 更新

- 启用 App Sandbox，应用名称统一为 ClipNest。
- 优先使用 ⌘⇧V 唤起；被占用时使用 ⌃⌘⇧V，菜单栏提示实际组合。
- 增加独立进程的沙盒验证流程，检查文本、图片、容器内文件恢复和复制，以及未授权外部文件访问被阻止。

## 升级注意

本版使用独立应用标识和容器，旧版历史暂不自动迁移，原数据不会被删除。请保留旧版数据目录 `~/Library/Application Support/ClipNest/`；新数据位于 `~/Library/Containers/com.clipnest.sandbox/Data/Library/Application Support/ClipNest/`。

自动粘贴、Finder 文件跨重启访问和登录启动尚未完成沙盒实机验证。现有文件历史没有实现安全作用域书签持久化；文件路径存在不保证可访问。自动粘贴不可用时可先复制，再手动按 ⌘V。旧版辅助功能授权不一定适用于本版。

## 签名状态

当前使用 ad-hoc 本地签名，**没有 Developer ID 签名及 Apple 公证**，也不是 Mac App Store 审核版本。首次打开可能被系统拦截，请参考 [Apple 官方打开说明](https://support.apple.com/guide/mac-help/mh40616/mac)。
