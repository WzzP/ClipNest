# ClipNest 0.1.2

原生 macOS 剪贴板管理工具，支持 macOS 14 及更新版本。

## 下载

下载 **ClipNest-0.1.2-universal-unsigned.zip**，解压后将 **ClipNest.app** 放入“应用程序”目录。支持 Apple Silicon 和 Intel；本次运行验证在 Apple Silicon 完成。SHA256SUMS.txt 用于校验下载文件。

## 更新

- 精简主界面，移除读取当前剪贴板、暂停、复制/粘贴按钮及最近监听状态。
- 使用左右方向键切换历史卡片，保留搜索光标移动与中文输入法候选词操作。
- 保留回车、双击粘贴以及右键复制；暂停记录仍可在设置中控制。
- 移除设置中的开发调试入口，简化授权说明。
- README 增加新版应用截图，使用示例内容。

## 升级注意

本版沿用 0.1.1 的应用标识和容器，可恢复 0.1.1 历史；0.1.0 历史暂不自动迁移，原数据不会被删除。请保留旧版数据目录 `~/Library/Application Support/ClipNest/`；新数据位于 `~/Library/Containers/com.clipnest.sandbox/Data/Library/Application Support/ClipNest/`。

自动粘贴、Finder 文件跨重启访问和登录启动尚未完成沙盒实机验证。现有文件历史没有实现安全作用域书签持久化；文件路径存在不保证可访问。自动粘贴不可用时可先复制，再手动按 ⌘V。旧版辅助功能授权不一定适用于本版。

## 签名状态

当前使用 ad-hoc 本地签名，**没有 Developer ID 签名及 Apple 公证**，也不是 Mac App Store 审核版本。首次打开可能被系统拦截，请参考 [Apple 官方打开说明](https://support.apple.com/guide/mac-help/mh40616/mac)。
