# ClipNest 0.1.3

原生 macOS 剪贴板管理工具，支持 macOS 14 及更新版本。

## 下载

下载 **ClipNest-0.1.3-universal-unsigned.zip**，解压后将 **ClipNest.app** 放入“应用程序”目录。支持 Apple Silicon 和 Intel；本次运行验证在 Apple Silicon 完成。SHA256SUMS.txt 用于校验下载文件。

## 更新

- 修复回车／双击粘贴的行为：现在先把所选记录复制到剪贴板，再尝试自动粘贴；不再出现未授予辅助功能权限时按回车却没有复制任何内容的情况。
- 没有辅助功能权限或没有可用目标应用时，内容已经复制好，面板照常收起，按提示手动按 ⌘V 即可。
- 已授权且有可用目标应用时，自动粘贴流程与 0.1.2 相同；右键“复制”的行为不变。
- README 同步更新回车／双击的行为说明。

## 升级注意

本版沿用 0.1.2 的应用标识和容器，历史数据无需迁移。0.1.0 历史仍不自动迁移，原数据不会被删除；请保留旧版数据目录 `~/Library/Application Support/ClipNest/`；新数据位于 `~/Library/Containers/com.clipnest.sandbox/Data/Library/Application Support/ClipNest/`。

自动粘贴、Finder 文件跨重启访问和登录启动尚未完成沙盒实机验证。现有文件历史没有实现安全作用域书签持久化；文件路径存在不保证可访问。未授予辅助功能权限时，回车／双击会先复制并在提示中说明，手动按 ⌘V 即可。旧版辅助功能授权不一定适用本版。

## 签名状态

当前使用 ad-hoc 本地签名，**没有 Developer ID 签名及 Apple 公证**，也不是 Mac App Store 审核版本。首次打开可能被系统拦截，请参考 [Apple 官方打开说明](https://support.apple.com/guide/mac-help/mh40616/mac)。
