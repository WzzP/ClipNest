# ClipNest 0.1.0

ClipNest 的首个版本：原生 macOS 剪贴板历史工具，按 **⌘⇧V** 从屏幕底部找回复制过的内容。

## 下载与安装

- 要求：macOS 14 或更新版本。
- 安装包：`ClipNest-0.1.0-universal-unsigned.zip`，包含 Apple Silicon 和 Intel 架构。
- 解压后将 `ClipNest.app` 拖入“应用程序”，从该目录打开。
- 可用 `SHA256SUMS.txt` 检查下载完整性。

**此版本使用 ad-hoc 本地签名，没有 Developer ID 签名，也未经过 Apple 公证。** 首次打开可能被 macOS 阻止。确认下载自本仓库且愿意信任此版本后，可按 [Apple 官方说明](https://support.apple.com/guide/mac-help/mh40616/mac)在“系统设置 → 隐私与安全性”中选择“仍要打开”。某些设备管理策略可能不允许此操作。

## 功能

- 文本、链接、图片和 Finder 多文件复制历史。
- 搜索、收藏、完整预览、再次复制及自动粘贴。
- 紧凑底部卡片栏、来源应用图标、后台缩略图加载。
- 本地持久化、历史数量设置、暂停记录和应用排除。
- 登录启动，以及中文输入法候选状态下的快捷键兼容。

## 使用说明

自动粘贴需要辅助功能权限；剪贴板读取权限与此不同。应用设置可以查看辅助功能状态。“复制”按钮可以配合手动 ⌘V 使用。

默认保存 200 条普通历史，收藏不计入数量上限。文件记录保存原路径，不备份文件本身；移动或删除原文件后，记录将无法粘贴。文本和图片附件保存在本机。

## 已知限制

- ad-hoc 构建更新后可能需要重新授予辅助功能权限。
- 暂无富文本保留、云同步、自定义分组和快捷键自定义。
- 单条文本上限 1 MB；图片上限 25 MB、1 亿像素。
- 捕获间隔 0.35 秒，极短时间内连续复制可能漏过中间内容。
- Intel 架构仅完成交叉编译检查，尚未在 Intel 实机验证；登录重启和各第三方应用的自动粘贴行为仍需更多实机覆盖。
